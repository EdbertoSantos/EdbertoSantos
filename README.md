###

<p data-importer="text" align="left">
Sou Edberto, desenvolvedor Back-End Júnior de Recife-PE, formado em Análise e Desenvolvimento de Sistemas e atualmente cursando Licenciatura em Computação na UFRPE.
<br><br>
Comecei minha trajetória em TI pelo lado de QA e suporte técnico, e hoje gosto de atuar construindo APIs — trabalho principalmente com Python (FastAPI) e Java (Spring Boot), sempre buscando entender o projeto de ponta a ponta: do modelo de dados até a integração com o front-end em React.
<br><br>
Em hackathons da Rede Cidadã e do Start+ Cibersegurança, participei de dois projetos full-stack que gosto bastante de contar: uma API que usa machine learning para prever vulnerabilidade social, e uma plataforma OSINT que verifica vazamentos de dados pessoais — nos dois, passei por tudo: back-end, front-end e a integração entre eles.
<br><br>
Atualmente estou me aprofundando em Java pela trilha da Capgemini e explorando o universo Salesforce pelo Trailhead, além de manter viva minha base em AWS e qualidade de software.
</p>
